# CODE POCKET

Бесплатный редактор HTML, CSS и JavaScript, адаптированный для iPhone и других устройств. Работает как устанавливаемое PWA.

## Возможности

- Три вкладки HTML, CSS и JavaScript.
- Запуск кода в изолированном iframe и просмотр сообщений консоли.
- Несколько проектов, переименование и автосохранение в `localStorage`.
- Три стартовых шаблона: лендинг, счётчик, профиль.
- Импорт HTML, экспорт полноценной HTML-страницы.
- Поддержка офлайн-режима после первой загрузки.
- Работает без аккаунтов, API и внешних библиотек.

## Запуск локально

Откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Можно также развернуть проект на GitHub Pages, Vercel или Netlify.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `code-pocket` на GitHub.
2. Загрузите файлы **из этой папки** в корень репозитория.
3. В репозитории откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветка **main**, каталог **/(root)** и нажмите **Save**.
5. После публикации откройте выданный GitHub Pages URL через Safari на iPhone.
6. В Safari нажмите **Поделиться → На экран «Домой» → Добавить**.

Для установки PWA нужен HTTPS (GitHub Pages предоставляет его автоматически). Проекты хранятся локально на данном устройстве и не синхронизируются между телефонами. Экспортируйте важные проекты в HTML для резервной копии.

## Ограничения и безопасность

Предпросмотр выполняет пользовательский JS в iframe с `sandbox="allow-scripts allow-modals allow-forms"`, без `allow-same-origin`. Не вводите секреты/API-ключи в код проекта. Импорт HTML не разделяет автоматически теги `<style>` и `<script>` на вкладки. Экспорт объединяет HTML, CSS и JS в один файл.
